第 1 章 命题与命题公式

考核要求 ：命题与联结词〔领会〕；命题公式的等值演算〔简单应用〕；联结词完备集〔领会〕 本章重点 ：命题及联结词、命题符号化、真值表、公式化简、等值演算 本章难点 ：命题公式化简与等值演算及其应用

1.1 命题与命题联结词

一、命题的基本概念【识记/领会】

  1. 命题 ：能判断真假的陈述句。
    • 两个条件缺一不可：①是 陈述句 ；②有 唯一确定的真假 。
    • 疑问句、祈使句、感叹句、悖论（如"我正在说谎"）、真值不确定的语句（如含未赋值变量的"x是偶数"）都 不是命题 。
  2. 真值 ：命题的判断结果。真命题真值为 真 （记 T 或 1 ），假命题真值为 假 （记 F 或 0 ）。任何命题真值唯一。
  3. 判断命题真假的两种情形 ：
    • 事实能直接判断（“雪是黑的”=假）；
    • 结论待确定但非真即假（“火星上有生命”，目前未知但必有一真一假，仍是命题）。
  4. 原子命题（简单命题） ：不能再拆分的命题。 复合命题 ：由原子命题和 命题联结词 按规则复合而成。
  5. 命题标识符 ：用大写字母（P、Q、R…）、带下标字母（P₁、P₂）表示命题。
    • 命题常量 ：表示确定命题，真值确定；
    • 命题变元（命题变项） ：只表示任意命题的位置， 本身真值不确定、不是命题 ；当用具体命题取代时（称 指派/赋值/解释 ）才有确定真值。

二、五大命题联结词（核心，必须背熟真值表）【简单应用】

设 P、Q 为命题，真值表如下（1=真，0=假）：

PQ否定 ¬P合取 P∧Q析取 P∨Q条件 P→Q双条件 P↔Q
0010011
0110110
1000100
1101111

1. 否定 ¬（一元，优先级最高） ¬P 读作"非 P"。P 真则 ¬P 假，P 假则 ¬P 真。

2. 合取 ∧（二元） ：P∧Q 读作"P 与 Q / P 并且 Q"。 全真才真，有假则假 。 自然语言中"既…又…““一方面…另一方面…““虽然…但是…““不但…而且…“都用 ∧。

注意：合取允许把 无内在联系 的两个命题连接（“2是素数 ∧ 北京是中国首都"为真），这与日常用语不同。

3. 析取 ∨（二元） ：P∨Q 读作"P 或 Q”。 有真则真，全假才假 。

  • 这是 可兼或（相容或） ：二者可同时为真。
  • “小王今晚要么看书要么听音乐”（可兼）用 ∨。
  • 排斥或（不可兼或） 用 (P∨Q)∧¬(P∧Q) 或 P↔¬Q 表示，如"小王要么是110米栏选手要么是三级跳远选手，没有兼项”。

4. 条件（蕴含）→（二元） ：P→Q 读作"如果 P 那么 Q"“P 是 Q 的充分条件"“Q 是 P 的必要条件"“仅当 Q 才有 P”。

  • P 称 前件（条件） ，Q 称 后件（结论） 。
  • 只有"前真后假”（P=1,Q=0）时为假，其余三种情况全为真 。
  • 前件为假时，P→Q 恒真 ，称为"善意推定（空真）"。
  • 逆命题：Q→P；否命题：¬P→¬Q；逆否命题：¬Q→¬P。
  • P→Q 与 ¬Q→¬P（逆否命题）等值 ；P→Q ⇔ ¬P∨Q。

5. 双条件（等价）↔（二元） ：P↔Q 读作"P 当且仅当 Q"“P 是 Q 的充要条件”。

  • 同真同假（真值相同）时为真，一真一假时为假 。
  • P↔Q ⇔ (P→Q)∧(Q→P)。

三、联结词运算次序与自然语言符号化【简单应用】

  1. 优先级（从高到低） ： ¬ > ∧ > ∨ > → > ↔ 。同级从左到右；括号最优先。
  2. 自然语言符号化步骤 ：①找出所有原子命题并用字母表示；②找出句中联结词；③按含义构造公式。
    • “若 P，则 Q"“P 推出 Q"“只要 P 就 Q"“P 成立仅当 Q 成立” → P→Q
    • “只有 P 才 Q” → Q→P（P 是 Q 的必要条件）
    • “P 当且仅当 Q"“P 即 Q” → P↔Q
    • “除非 P，否则 Q” → ¬P→Q
  3. 多条件符号化模板 ：
    • “若 P₁ 且 P₂，则 Q”：P₁∧P₂→Q
    • “若 P₁ 或 P₂，则 Q”：P₁∨P₂→Q
    • “若 P₁，则 Q₁ 且 Q₂”：P₁→Q₁∧Q₂
    • “若 P₁，则 Q₁ 或 Q₂”：P₁→Q₁∨Q₂

1.2 命题公式的等值演算

一、合式公式与公式层次【识记】

  1. 合式公式（命题公式/公式）递归定义 ：
    • 基础：单个命题变元或常量（T、F）是合式公式；
    • 归纳：若 A 是公式，则 ¬A 是公式；若 A、B 是公式，则 (A∧B)、(A∨B)、(A→B)、(A↔B) 是公式；
    • 界限：仅由有限次上述步骤得到的才是合式公式。
  2. 公式的层次（n 层公式） ：
    • 单个命题变元/常量为 0 层公式 ；
    • 若 A 是 n 层，则 ¬A 是 n+1 层 ；
    • 若 A、B 层次分别为 n₁、n₂，则 A∧B、A∨B、A→B、A↔B 的层次为 max(n₁,n₂)+1 。
  3. 赋值（指派/解释） ：给公式中每个命题变元指定一个真值。含 n 个变元的公式共有 2ⁿ 种赋值 。
    • 使公式为真的赋值叫 成真赋值 ，为假的叫 成假赋值 。

二、真值表【简单应用，必会】

列真值表步骤 ：①列出公式所有变元，写出全部 2ⁿ 种赋值；②按从内层到外层（按公式层次）逐列计算各子公式真值；③最后一列即整个公式真值。

真值表是判定公式类型、判定等值、求范式的"万能工具”，必须熟练、不出错。

三、公式的三种类型【领会/简单应用】

设 A 是命题公式：

  • 重言式（永真式/逻辑有效式） ：A 在 所有赋值 下均为真（真值表末列全 1）。
  • 矛盾式（永假式） ：A 在 所有赋值 下均为假（末列全 0）。
  • 可满足公式 ： 至少存在一种 赋值使 A 为真（末列至少一个 1）。

关系：

  • 重言式一定是可满足公式，反之不然；
  • 矛盾式一定不可满足；
  • 若 A 是重言式，则 ¬A 是矛盾式；
  • 判定方法 ：真值表法、等值演算法。

四、等值（逻辑等价）与蕴涵【简单应用】

  1. 等值 ⇔（⇔ 不是联结词，是公式间关系符） ：设 A、B 是两个命题公式，若 A↔B 是 重言式 （即 A、B 在 任一赋值下真值都相同 ），称 A 与 B 等值（等价），记 A⇔B （或 A=B）。
    • 判定：真值表法（两列完全相同）、等值演算法。
  2. 蕴涵 ⇒ ：若公式 A→B 是 重言式 ，称 A 蕴涵 B，记 A⇒B 。
    • A⇒B 当且仅当：凡使 A 为真的赋值都使 B 为真（ A 的成真赋值集合 ⊆ B 的成真赋值集合 ）。

七、两个演算规则【领会】

  1. 代入规则 ：在重言式中，把某命题变元 处处 用同一公式替换，结果仍是重言式。（只对重言式适用，且必须处处替换）
  2. 替换规则（置换规则） ：若公式中某子公式 C 与 D 等值（C⇔D），可用 D 替换 C（不必处处），所得公式与原公式等值。

等值演算就是反复用基本等值定律 + 替换规则，把公式化到目标形式。 证 A⇔B 的常用方法 ：从 A 出发逐步等值变形到 B；或分别化简到同一式；或证明 A↔B 为重言式。

1.3 联结词完备集

一、其他联结词【识记】

  1. 与非 ↑ ：P↑Q ⇔ ¬(P∧Q)。性质：P↑P⇔¬P；(P↑Q)↑(P↑Q)⇔P∧Q；(P↑P)↑(Q↑Q)⇔P∨Q。
  2. 或非 ↓ ：P↓Q ⇔ ¬(P∨Q)。性质：P↓P⇔¬P；(P↓Q)↓(P↓Q)⇔P∨Q；(P↓P)↓(Q↓Q)⇔P∧Q。
  3. 条件否定 ：P↔Q 的否定等；还有不可兼析取（异或 ⊕）：P⊕Q⇔(P∨Q)∧¬(P∧Q)⇔¬(P↔Q)。

二、联结词完备集（功能完备集）【领会】

  1. 完备集 ：若任意一个真值函数都能用该集合中的联结词表示，则称其为联结词完备集。
  2. 因为 ∧、∨、¬ 已能表示一切公式，故 {¬,∧,∨} 完备；
    • 由 A∨B⇔¬(¬A∧¬B)，故 {¬,∧} 完备；
    • 由 A∧B⇔¬(¬A∨¬B)，故 {¬,∨} 完备；
    • 由与非可表示 ¬、∧、∨，故 {↑} 单独完备；
    • 由或非可表示 ¬、∧、∨，故 {↓} 单独完备。
  3. 最小联结词组 ：{¬,∨}、{¬,∧}、{↑}、{↓}（再去掉任一个就不完备）。

注意：{∧,∨} 不完备（无法表示否定）；{¬,→} 也完备（因 A∧B⇔¬(A→¬B)）。

第 2 章 命题逻辑的推理理论

考核要求 ：范式〔领会〕；主范式〔简单应用〕；自然推理系统〔简单应用〕 本章重点 ：主范式表示及相互转换；用 P 规则、T 规则、CP 规则进行命题推理 本章难点 ：命题推理及其应用

2.1 范式

一、基本概念【识记/领会】

  1. 简单析取式 ：由有限个命题变元或其否定构成的 析取式 ，如 P∨¬Q∨R。 简单合取式 ：由有限个命题变元或其否定构成的 合取式 ，如 ¬P∧Q∧¬R。
    • 一个变元（或其否定）本身既可看作简单析取式，也可看作简单合取式。
  2. 析取范式 ：由有限个 简单合取式 用 ∨ 连接而成，形如 A₁∨A₂∨…∨Aₙ（每个 Aᵢ 是简单合取式）。 合取范式 ：由有限个 简单析取式 用 ∧ 连接而成，形如 B₁∧B₂∧…∧Bₙ（每个 Bᵢ 是简单析取式）。
  3. 范式存在定理 ： 任意命题公式都存在与之等值的析取范式和合取范式 。
  4. 范式（非"主"范式） 一般不唯一 。

二、求范式三步法【简单应用】

  1. 消去 →、↔ ：A→B 换成 ¬A∨B；A↔B 换成 (¬A∨B)∧(A∨¬B)（或(A∧B)∨(¬A∧¬B)）。
  2. 否定深入（消去双重否定、用德摩根律） ：把 ¬ 移到命题变元前。 ¬¬A⇒A；¬(A∨B)⇒¬A∧¬B；¬(A∧B)⇒¬A∨¬B。
  3. 用分配律归整 ：
    • 求 析取范式 用 ∧ 对 ∨ 的分配 ：A∧(B∨C)⇔(A∧B)∨(A∧C)；
    • 求 合取范式 用 ∨ 对 ∧ 的分配 ：A∨(B∧C)⇔(A∨B)∧(A∨C)。

记忆： 析取范式 = 合取式的析取（外层∨）；合取范式 = 析取式的合取（外层∧） 。

2.2 主范式（本章核心，必考）

一、小项（极小项 mᵢ）【领会】

  1. 定义 ：含 n 个变元的简单合取式，若每个变元与其否定 不同时出现，且二者之一恰出现一次 ，称该简单合取式为小项（极小项）。
  2. 个数 ：n 个变元共有 2ⁿ 个小项 ，记 m₀,m₁,…,m2ⁿ−1。
  3. 编码规则（关键） ：变元按字典序排列； 变元本身记 1，变元的否定记 0 ；所得二进制数转十进制即下标 i。
    • 例（P,Q）：¬P∧¬Q = m₀(00)；¬P∧Q = m₁(01)；P∧¬Q = m₂(10)；P∧Q = m₃(11)。
  4. 性质 ：
    • 每个小项 只有一个成真赋值 ，就是与其编码相同的那个赋值；
    • 任意两个不同小项的合取是矛盾式：mᵢ∧mⱼ⇔F (i≠j)；
    • 全体小项的析取是重言式：m₀∨m₁∨…∨m2ⁿ−1⇔T。

二、大项（极大项 Mᵢ）【领会】

  1. 定义 ：含 n 个变元的简单析取式，每个变元与其否定恰出现一次。
  2. 个数 ：共 2ⁿ 个大项 ，记 M₀,M₁,…。
  3. 编码规则（与小项相反） ： 变元本身记 0，变元的否定记 1 。
    • 例（P,Q）：P∨Q = M₀(00)；P∨¬Q = M₁(01)；¬P∨Q = M₂(10)；¬P∨¬Q = M₃(11)。
  4. 性质 ：
    • 每个大项 只有一个成假赋值 （即其编码）；
    • 任意两个不同大项的析取是重言式：Mᵢ∨Mⱼ⇔T (i≠j)；
    • 全体大项的合取是矛盾式：M₀∧M₁∧…∧M2ⁿ−1⇔F。
  5. 小项与大项关系 ： ¬mᵢ ⇔ Mᵢ，¬Mᵢ ⇔ mᵢ （同下标互补）。

三、主析取范式与主合取范式【简单应用，必考计算】

  1. 主析取范式 ：与公式等值、且每个简单合取式都是 小项 的析取范式，记 A ⇔ Σ mᵢ = ∨ mᵢ 。
  2. 主合取范式 ：与公式等值、且每个简单析取式都是 大项 的合取范式，记 A ⇔ Π Mᵢ = ∧ Mᵢ 。
  3. 唯一性（重要定理） ： 任何命题公式的主析取范式和主合取范式都是唯一的 （矛盾式主析取范式为空/0，重言式主合取范式为空/1，按约定处理）。

四、求主范式的两大方法【简单应用】

方法一：真值表法（最稳，推荐）

  • 主析取范式 ：找出公式的 全部成真赋值 ，每个成真赋值对应一个小项（成真赋值的二进制编码即小项下标），把这些小项析取。
  • 主合取范式 ：找出公式的 全部成假赋值 ，每个成假赋值对应一个大项（成假赋值编码即大项下标），把这些大项合取。
  • 两组下标 互补 ：若主析取下标集合为 S，则主合取下标集合为 {0,1,…,2ⁿ−1} − S。

方法二：等值演算法

  • 先求析取（合取）范式；
  • 删去矛盾（重言）的简单式，合并重复项；
  • 对缺少变元 P 的简单式用"补变元"技巧：
    • 补小项：A ⇔ A∧(P∨¬P)，再分配展开（合取式补变元用 ∧(P∨¬P)）；
    • 补大项：A ⇔ A∨(P∧¬P)，再分配展开（析取式补变元用 ∨(P∧¬P)）。

例 ：求 (P→Q)→R 的主析取/主合取范式（3 变元，8 个小项）。 真值表得成真赋值为 PQR = 001,011,100,101,111（即 m₁,m₃,m₄,m₅,m₇）；成假为 000,010,110（M₀,M₂,M₆）。 ∴ 主析取 = m₁∨m₃∨m₄∨m₅∨m₇；主合取 = M₀∧M₂∧M₆。

五、主范式的应用【简单应用】

  1. 求成真/成假赋值 ：主析取出现的小项下标 = 成真赋值；主合取出现的大项下标 = 成假赋值。
  2. 判公式类型 ：
    • 主析取范式含 全部 2ⁿ 个小项 ⇔ 重言式（等价地，主合取范式不含任何大项）；
    • 主析取范式 不含任何小项 （为 F）⇔ 矛盾式（主合取含全部大项）；
    • 含部分小项 ⇔ 可满足公式。
  3. 判两公式等值 ：主析取（主合取）范式相同则等值。
  4. 解实际逻辑问题 ：由条件列出成真情形，写出主析取范式，得到满足条件的全部方案。

2.3 自然推理系统

一、有效推理的概念【领会】

  1. 设前提 A₁,A₂,…,Aₖ，结论 B。若 (A₁∧A₂∧…∧Aₖ)→B 是重言式 ，则称从前提推出结论 B 的推理 有效（正确） ，B 称前提的 有效结论 ，记 A₁,A₂,…,Aₖ ⇒ B。
  2. 判定方法 ：①真值表法；②主（析取）范式法；③ 推理（演绎）法 ——考试重点。
  3. 注意：推理有效只保证” 若前提全真则结论必真 “，不要求前提事实上为真。

二、常用推理定律（重言蕴涵式，即第1章九条）【领会】

  • 化简：A∧B⇒A，A∧B⇒B
  • 附加：A⇒A∨B
  • 假言推理 MP：A, A→B ⇒ B
  • 拒取式 MT：¬B, A→B ⇒ ¬A
  • 析取三段论：¬A, A∨B ⇒ B
  • 假言三段论：A→B, B→C ⇒ A→C
  • 构造性二难：(A→B)∧(C→D), A∨C ⇒ B∨D
  • 合取引入：A, B ⇒ A∧B

三、三条推理规则（必须规范使用）【简单应用】

  1. P 规则（前提引入规则） ：证明的任何步骤都可引入已知前提。
  2. T 规则（结论引入/变换规则） ：证明的任何步骤，都可依据 等值式（标 T E）或蕴涵式（标 T I） ，由前面已得结论推出新结论。
    • 书写惯例：T，(行号)，(I/E)；I 表蕴涵定律，E 表等值定律。
  3. CP 规则（条件证明/附加前提规则） ：要证 H ⇒ (R→C)，可把 R 作为附加前提 加入，只要证出 H, R ⇒ C 即可。
    • 原理：输出律 (H∧R)→C ⇔ H→(R→C)。 当结论是条件式时首选 CP 规则 。

四、三种证明方法【简单应用】

  1. 直接证法 ：从前提出发，反复用 P、T 规则直接推到结论。
  2. 附加前提法（CP） ：结论为条件式 R→C 时，把 R 加入前提，证 C。
  3. 反证法（归谬法） ：要证 H⇒C，把 ¬C 作为附加前提 ，若与已知前提共同推出矛盾（某式及其否定），则 C 成立。
    • 理论依据：(H∧¬C)→F ⇔ H→C。
  4. 分情况证明 ：证 (P∨Q)→R，分别证 P→R 与 Q→R。

标准书写格式示例 （证：P→Q, Q→R, P ⇒ R）：

步骤公式依据
(1)PP
(2)P→QP
(3)QT,(1)(2),I（假言推理）
(4)Q→RP
(5)RT,(3)(4),I

第 3 章 谓词逻辑

考核要求 ：谓词概念〔领会〕；量词与合式公式〔识记〕；等价式与蕴涵式〔领会〕；前束范式〔简单应用〕；谓词演算推理〔简单应用〕 本章重点 ：用谓词与量词表示命题、确定量词辖域、化前束范式、谓词演算推理 本章难点 ：①带量词公式化为前束范式；②谓词演算推理

3.1 谓词的概念与表示

一、个体词与谓词【识记/领会】

  1. 个体词（主词） ：命题中所描述的对象。
    • 个体常元 ：具体确定的对象，用 a,b,c… 表示；
    • 个体变元 ：抽象/泛指的对象，用 x,y,z… 表示；
    • 个体域（论域） ：个体变元的取值范围，记 D。 全总个体域 指宇宙间一切对象组成的最大个体域。
  2. 谓词 ：刻画个体的 性质 或个体之间 关系 的词，用 P,Q,R… 表示。
    • P(x) 称 一元谓词 （表性质）；Q(x,y) 称 二元谓词 （表关系）；n 个个体变元的谓词称 n 元谓词 。
    • 谓词常元 表确定的性质/关系； 谓词变元 表抽象未知的性质/关系。
  3. 命题函数（谓词填式） ：形如 P(x)、Q(x,y)，因含未指定个体， 真值不确定，不是命题 。当个体变元用具体个体取代（特殊化/赋值）后才成为命题。
    • 0 元谓词 （不含个体变元）就是命题。
  4. 复合命题函数 ：用 ¬、∧、∨、→、↔ 把若干命题函数连接而成。
  5. 谓词逻辑是命题逻辑的推广 ：命题逻辑是谓词逻辑在"不分析句子内部结构"时的特例。

3.2 量词与合式公式

一、两个量词【领会，必会符号化】

  1. 全称量词 ∀ ：表示"所有、每一个、任意、凡、一切”。∀x P(x) 读作"对所有 x，P(x) 成立”。
  2. 存在量词 ∃ ：表示"存在、有一个、至少有一个、有些”。∃x P(x) 读作"存在 x 使 P(x) 成立”。

二、特性谓词（限定论域）的正确用法【简单应用，高频易错】

当采用 全总个体域 时，用"特性谓词 M(x)“限定讨论范围，连接词有严格规定：

汉语符号化连接词
所有 M 都是 P（每一个 M 都 P）∀x (M(x)→P(x))全称用 →
有的 M 是 P（存在 M 是 P）∃x (M(x)∧P(x))存在用 ∧

记忆铁律： 全称配蕴含 →，存在配合取 ∧ 。用反会出错（如∀x(M(x)∧P(x))会要求所有对象都是M且P，过强）。

典型符号化 （设 M(x)：x 是人）：

  • “所有的人都要呼吸”（F(x)：x 呼吸）：∀x(M(x)→F(x))。
  • “有的人聪明”（G(x)：x 聪明）：∃x(M(x)∧G(x))。
  • “所有实数都有平方根"需注意否定对象；“没有不犯错误的人”：¬∃x(M(x)∧¬F(x)) ⇔ ∀x(M(x)→F(x))。
  • “直线 A 与直线 B 平行，当且仅当 A、B 不相交”：P(A,B)↔¬∃x(Q(x,A)∧Q(x,B))。

三、约束关系【识记】

  1. 指导变元（作用变元） ：量词后紧跟的变元，如 ∀x 中的 x。

  2. 量词的辖域（作用域） ：量词后紧跟的原子公式，或量词后括号内的整个公式。

  3. 约束出现 / 自由出现 ：

    • 在 ∀x（或 ∃x）辖域内、且与指导变元同名的变元是 约束出现 （受该量词约束）；
    • 不被任何量词约束的变元是 自由出现 。
    • 一个变元可同时有约束出现和自由出现。

  4. 两条改写规则（保证公式意义不变） ：

    • 约束变元改名规则 ：把某量词的指导变元及其辖域中所有约束出现 一起 换成新变元（其余未用名），其余不变。
    • 自由变元代入规则 ：把自由出现的变元 处处 换成未曾出现过的新变元。

    > 目的：使一个变元只呈一种身份（避免既是约束又是自由造成混淆）。

四、谓词合式公式【识记】

  • 原子谓词公式 ：不出现命题联结词和量词的谓词命名式 P(x₁,…,xₙ)。
  • 递归定义：原子公式是合式公式；若 A、B 是，则 ¬A、A∧B、A∨B、A→B、A↔B 是；若 A 是、x 是个体变元，则 ∀xA、∃xA 是；有限次得到的才是。

五、量词与否定（量词德摩根律）【简单应用】

  • ¬∀x P(x) ⇔ ∃x ¬P(x) （“并非所有都…“等价于"存在不…的”）
  • ¬∃x P(x) ⇔ ∀x ¬P(x) （“不存在…“等价于"所有都不…"）

3.3 谓词演算的等价式与蕴涵式

一、解释（赋值）与公式分类【领会】

  1. 一个解释（赋值）包含 ：①指定一个 非空个体域 D ；②为个体常元指定 D 中元素；③为函数指定 D 上的函数；④为谓词指定 D 上的关系。
  2. 分类：在 所有解释下都真 称 有效公式（永真式/逻辑有效式） ；都假称 矛盾（不可满足） ；至少有一解释真称 可满足 。
  3. 等价 ：若 A↔B 是有效公式，称 A 与 B 等值，记 A⇔B。

二、常用等值式与蕴涵式（必背）【简单应用】

1. 命题定律的推广 ：把命题等值式中的命题变元代以谓词公式，仍成立。

2. 量词否定等值式 ：¬∀xA(x)⇔∃x¬A(x)；¬∃xA(x)⇔∀x¬A(x)。

3. 量词作用域的收缩与扩张 （设 B 中不含 x ）：

  • ∀x(A(x)∧B) ⇔ ∀xA(x)∧B；　∀x(A(x)∨B) ⇔ ∀xA(x)∨B
  • ∃x(A(x)∧B) ⇔ ∃xA(x)∧B；　∃x(A(x)∨B) ⇔ ∃xA(x)∨B
  • ∀x(A(x)→B) ⇔ ∃x A(x)→B ；　∀x(B→A(x)) ⇔ B→∀xA(x)
  • ∃x(A(x)→B) ⇔ ∀x A(x)→B ；　∃x(B→A(x)) ⇔ B→∃xA(x)

4. 量词分配等值式（仅这两个方向成立） ：

  • ∀x(A(x)∧B(x)) ⇔ ∀xA(x)∧∀xB(x) （全称对 合取 可分配）
  • ∃x(A(x)∨B(x)) ⇔ ∃xA(x)∨∃xB(x) （存在对 析取 可分配）

5. 量词分配蕴涵式（反向只蕴涵、不等值） ：

  • ∀xA(x)∨∀xB(x) ⇒ ∀x(A(x)∨B(x))
  • ∃x(A(x)∧B(x)) ⇒ ∃xA(x)∧∃xB(x)

6. 多重量词 ：

  • 同类量词可交换：∀x∀y A ⇔ ∀y∀x A；∃x∃y A ⇔ ∃y∃x A。
  • 异类量词顺序不可随意交换 ；强弱关系： ∀x∀y A ⇒ ∃y∀x A ⇒ ∀x∃y A ⇒ ∃x∃y A （∀∀ 最强，∃∃ 最弱）。

3.4 前束范式

一、定义【领会】

前束范式 ：所有量词都移到公式最前面，且每个量词的辖域都是其后整个公式尾，形如 (Q₁x₁)(Q₂x₂)…(Qₖxₖ) M ，其中 Qᵢ 为 ∀ 或 ∃， M 中不再含量词 （M 称母式/基式）。

  • 前束范式存在定理 ： 任意谓词公式都存在与之等值的前束范式 。
  • 前束范式 一般不唯一 （量词顺序、母式形式可能不同）。

二、求前束范式四步法【简单应用，必考】

  1. 消去 →、↔ （用 A→B⇔¬A∨B 等）。
  2. 否定深入 ：用 ¬∀⇔∃¬、¬∃⇔∀¬ 及德摩根律，把 ¬ 移到原子谓词前。
  3. 约束变元改名 / 自由变元代入 ：使受不同量词约束的变元不同名、约束变元与自由变元不同名。
  4. 量词前移 ：利用作用域扩张等值式把所有量词依次移到最左端（辖域拉到末尾）。

例 ：∀x(P(x)→∃y Q(x,y))： 改名/前移：⇔ ∀x(¬P(x)∨∃y Q(x,y)) ⇔ ∀x∃y(¬P(x)∨Q(x,y))（y 不在¬P中，∃y 可前移）。

3.5 谓词演算的推理理论

一、四条量词消去/引入规则【简单应用，核心】

规则名称形式关键限制
UI全称消去（全称特指）∀x A(x) ⇒ A(y)，或 ⇒ A(c)y 为任意自由变元；c 为任意个体常元
UG全称引入（全称推广）A(y) ⇒ ∀x A(x)y 在前提中 不自由出现 、且 y 是 任意 选定（不能是 EI 引入的特定常元）
EI存在消去（存在特指）∃x A(x) ⇒ A(c)c 必须是此前提/前面步骤中从未出现过的新常元
EG存在引入（存在推广）A(c) ⇒ ∃x A(x)，或 A(y)⇒∃x A(x)取代 c（或自由 y）的 x 须在 A 中未出现

二、使用规则的注意事项（易错点）

  1. 对同一变元既要 EI 又要 UI 时，先 EI 后 UI ：先由 ∃ 取一个特定常元 c，再让 ∀ 也取 c，才能保证二者指同一个体；顺序反了无法关联。
  2. EI 引入的特定常元 c 绝不能用 UG 推广成 ∀ （c 只是"某一个”，不代表任意）。
  3. 多个 ∃ 前提的特指常元不能混用 ：∃x A(x) 取 c，∃x B(x) 应另取新常元 d。
  4. 推理仍配合命题逻辑的 P 规则、T 规则、CP 规则、反证法 。

第 4 章 集合

考核要求 ：集合基本概念〔领会〕；集合的运算〔简单应用〕；有序对与笛卡儿积〔简单应用〕 本章重点 ：集合的表示、幂集、集合运算、集合恒等式证明 本章难点 ：集合运算及集合恒等式证明

4.1 集合的基本概念

一、集合及其表示【识记/领会】

  1. 集合 ：一些确定的、彼此不同的对象组成的整体。组成集合的对象称 元素 。
    • a 是 A 的元素记 a∈A （a 属于 A）；否则记 a∉A。
  2. 集合的三个特性： 确定性、互异性（无重复元素）、无序性 （{a,b}={b,a}）。
  3. 表示法 ：
    • 列举法（枚举法） ：A={1,2,3}；
    • 描述法（谓词法） ：A={x | P(x)}，A={x | x 是偶数}；
    • 图示法（文氏图 Venn 图） ：用矩形表全集 E、圆/椭圆表集合，直观表示集合关系与运算。
  4. 常用数集：N 自然数集、Z（或 I）整数集、Q 有理数集、R 实数集、C 复数集；Z⁺ 正整数集。

二、集合间关系【领会】

  1. 相等 ：A=B 当且仅当 A、B 含完全相同的元素，即 A⊆B 且 B⊆A。
  2. 子集 ：若 A 的每个元素都属于 B，则 A⊆B（A 包含于 B）。
    • 包含的自反性 ：A⊆A； 传递性 ：A⊆B 且 B⊆C ⇒ A⊆C。
  3. 真子集 ：A⊆B 且 A≠B，记 A⊂B（A 真包含于 B）。
  4. 空集 ∅ ：不含任何元素的集合。 ∅ 是任何集合的子集 （∅⊆A），且空集唯一。
  5. 全集 E（U） ：在一定范围内包含所有讨论对象的集合。
  6. 幂集（重点） ：集合 A 的所有子集组成的集合，记 P(A)（或 2^A） ： P(A) = { x | x⊆A }。
    • 核心公式：|P(A)| = 2^|A| （A 有 n 个元素，则幂集有 2ⁿ 个元素）。
    • 例：A={a,b}，P(A)={∅,{a},{b},{a,b}}，共 4=2² 个。
    • ∅ 与 A 本身一定在幂集中。
  7. 基数（势） ：集合元素个数，记 |A|。|A| 有限为有限集，否则无限集。
    • 可数集（能与自然数集或其有限子集一一对应，如 N、Z、Q）与不可数集（如实数集 R）——属"了解"层次。

4.2 集合的运算

一、五种基本运算（必会计算）【简单应用】

设全集为 E，A、B 为集合：

运算定义记忆
并 A∪B{x ∣ x∈A 或 x∈B}把两集合元素合起来
交 A∩B{x ∣ x∈A 且 x∈B}取公共元素；A∩B=∅ 称 A、B 不相交
相对差 A−B （A\B）{x ∣ x∈A 且 x∉B} = A∩~B从 A 中去掉属于 B 的
绝对补 ~A（Aᶜ）E−A = {x ∣ x∈E 且 x∉A}全集中去掉 A
对称差 A⊕B(A−B)∪(B−A) = (A∪B)−(A∩B)属于 A 或 B 但不同时属于二者
  • 对称差性质：A⊕B=B⊕A（交换）；A⊕A=∅；A⊕∅=A；A⊕B=(A∩~B)∪(~A∩B)。
  • 广义并 ∪A ：集族 A 中所有元素（集合）的并； 广义交 ∩A ：集族所有元素的交。 例 A={{1,2},{2,3}}：∪A={1,2,3}，∩A={2}。

  • A∩B = A

四、集合恒等式的证明方法【简单应用】

  1. 集合演算法（等值代入） ：从等式一侧出发，用恒等式逐步变形到另一侧（最常用）。
  2. 双向包含法（最根本） ：证 A=B 就证 A⊆B 且 B⊆A。任取 x∈左，推出 x∈右；再反向。
  3. 命题演算法 ：把 x∈A 当作命题，用逻辑等值式推导。
  4. 文氏图法 ：直观验证（不宜作为严格证明的唯一依据）。

常用包含证明模板 ： 证 A⊆B：任取 x∈A →（由定义/恒等式展开）→ x∈B。 证两集合相等：分别证左右互相包含。

4.3 有序对与笛卡儿积

一、有序对【领会】

  1. 有序对（序偶） ：记 <x, y> （或 (x,y)），集合论定义 <x,y>={{x},{x,y}} 。
  2. 核心性质 ：
    • <x,y>=<u,v> 当且仅当 x=u 且 y=v ；
    • 当 x≠y 时， <x,y> ≠ <y,x> （有序，区别于无序对 {x,y}）。
  3. 有序 n 元组 ： <x₁,x₂,…,xₙ> 可递归定义为 <<x₁,…,xₙ₋₁>, xₙ>；相等当且仅当各对应分量相等。

二、笛卡儿积（直积）【简单应用】

  1. 定义 ：A×B = { <x,y> | x∈A 且 y∈B }。 推广：A₁×A₂×…×Aₙ = { <x₁,…,xₙ> | xᵢ∈Aᵢ }；Aⁿ=A×A×…×A（n 个）。
  2. 基数公式 ： |A×B| = |A|·|B| （有限集）。
  3. 性质 ：
    • A×∅ = ∅，∅×A = ∅；
    • 一般不满足交换律 ：A×B ≠ B×A（除非 A=B 或含空集）；
    • 一般不满足结合律：(A×B)×C ≠ A×(B×C)（元素结构不同）；
    • 对 ∪、∩ 满足分配律 （左右均可）： A×(B∪C) = (A×B)∪(A×C)； A×(B∩C) = (A×B)∩(A×C)； (A∪B)×C = (A×C)∪(B×C)； (A∩B)×C = (A×C)∩(B×C)； A×(B−C) = (A×B)−(A×C)。
  4. 包含性质 ：若 A⊆C 且 B⊆D，则 A×B⊆C×D；反之，当 A、B 均非空时 A×B⊆C×D 可推出 A⊆C 且 B⊆D（涉及空集时反推不成立）。

★ 本章解题方法速查

  1. 幂集 ：n 元集合幂集元素数 = 2ⁿ；列幂集按元素个数从 0（∅）到 n 有序罗列，防遗漏。
  2. 集合运算 ：差先化 A−B=A∩~B；对称差化 (A∩~B)∪(~A∩B)；再用德摩根、分配、吸收。
  3. 证恒等式 ：优先集合演算；卡壳就用"任取 x"的双向包含法。
  4. 证 A⊆B ：用 A∪B=B、A∩B=A、A−B=∅ 等等价刻画转换。
  5. 笛卡儿积 ：元素是有序对；计数用乘法原理；注意它不交换、不结合，但对并交可分配。

考核要求 ：关系及性质〔领会〕；关系运算〔领会〕；等价关系与序关系〔简单应用〕；函数〔领会〕 本章重点 ：集合上的关系及其运算、函数及其运算（ 全书分值最高的章之一 ） 本章难点 ：等价关系、相容关系、序关系的判定与证明

5.1 关系及关系的性质

一、二元关系的定义【领会】

  1. 二元关系 ：若 R 是 A×B 的任一子集，则称 R 为 A 到 B 的二元关系。
    • <x,y>∈R 记为 xRy ； <x,y>∉R 记为 xR̸y。
    • A 上的关系 ：A×A 的子集。
  2. 定义域、值域、域 ：
    • dom R = { x | ∃y, <x,y>∈R }（所有第一分量）；
    • ran R = { y | ∃x, <x,y>∈R }（所有第二分量）；
    • fld R = dom R ∪ ran R。
  3. A 到 B 的关系总数：A 有 m 元、B 有 n 元时，A×B 有 mn 个有序对，故共有 2^(mn) 个不同关系；A 上共有 2^(n²) 个关系。
  4. 三个特殊关系（A 上） ：
    • 空关系 ∅ （A×A 的空子集）；
    • 全域关系 E_A = A×A ；
    • 恒等关系 I_A = { <x,x> | x∈A } 。

二、关系的三种表示【领会】

  1. 集合表示法 ：列举法 R={<1,1>,<1,2>,…} 或描述法 R={<x,y>|P(x,y)}。
  2. 关系矩阵 M_R ：设 A={a₁,…,aₙ}，R 是 A 上关系，M_R=(mᵢⱼ)ₙₓₙ， mᵢⱼ=1 若 <aᵢ,aⱼ>∈R，否则 0 （布尔矩阵）。
  3. 关系图 G_R ：A 中元素为顶点；若 <aᵢ,aⱼ>∈R，画一条从 aᵢ 指向 aⱼ 的有向边；<aᵢ,aᵢ> 画成自环。

三、关系的五种性质（核心，必须会判定）【简单应用】

设 R 是 A 上关系：

  • 对称与反对称 可以同时满足 ：恒等关系 I_A、空关系 ∅ 既对称又反对称。
  • 恒等关系 I_A：自反、对称、反对称、传递；空关系：反自反、对称、反对称、传递（A 非空时不自反）。
  • 全域关系 E_A：自反、对称、传递，但不反对称（|A|>1）。

5.2 关系的运算

一、常规集合运算【领会】

关系是有序对集合，故可进行 并 ∪、交 ∩、差 −、补 ~ ，结果仍是关系。

  • 若 R、S 都自反/对称/传递，则 R∩S 也保持相应性质（交保持五性质）；
  • 并：自反、对称保持，但 传递性不一定保持 （重点反例）。

二、逆关系【领会】

R⁻¹ = { <y,x> | <x,y>∈R } （把每个有序对颠倒）。

  • 关系矩阵： MR⁻¹ = M_R 的转置 M_Rᵀ ；关系图：所有边反向。
  • 性质：(R⁻¹)⁻¹=R；(R∘S)⁻¹ = S⁻¹∘R⁻¹（ 逆的复合要交换次序 ）；
  • R 对称 ⇔ R=R⁻¹。

三、复合关系（合成关系）【简单应用，必考计算】

  1. 定义（右复合，先 S 后 R） ： R∘S = { <x,z> | ∃y 使 <x,y>∈S 且 <y,z>∈R } 。 （即先走 S 再走 R；与函数 (g∘f)(x)=g(f(x)) 先 f 后 g 一致。）
  2. 关系矩阵的布尔运算 ：布尔加 ∨（逻辑或）、布尔乘 ∧（逻辑与）。 MR∘S = M_S ⊙ M_R （布尔矩阵乘法，乘法用∧、加法用∨）。
  3. 关系幂 ：R⁰=I_A；R¹=R；Rn+1=Rⁿ∘R。
    • R^m∘R^n=Rm+n；(R^m)^n=Rmn。
  4. 性质 ：复合满足 结合律 (R∘S)∘T=R∘(S∘T)；一般 不满足交换律 ；I_A 是复合的单位元：I_A∘R=R∘I_A=R。

5.3 等价关系与序关系

一、等价关系与等价类【简单应用，重点】

  1. 等价关系 ：A 上同时满足 自反、对称、传递 的关系 R。记为 ~。 典型：数的相等、模 n 同余、三角形全等、同班同学。
  2. 模 n 同余关系 （必会例子）：在整数集上 x≡y (mod n) 当且仅当 n 整除 (x−y)。它是等价关系，恰有 n 个等价类 （余数 0,1,…,n−1）。
  3. 等价类 ：[a]_R = { x | x∈A 且 <a,x>∈R }，称 a 为代表元。 性质：①同一等价类中元素互相等价；②[a]=[b] 当且仅当 aRb；③[a]≠[b] 则 [a]∩[b]=∅；④所有等价类的并等于 A。
  4. 商集 ：A/R = { [a]_R | a∈A }（所有等价类作元素组成的集合）。
  5. 划分 ：把 A 分成若干两两不交、并为 A 的非空子集（划分块/分块）。 核心定理：A 上的等价关系与 A 的划分一一对应 ——等价关系确定一个划分（商集），每个划分也确定一个等价关系（同块即等价）。
  6. 相容关系 ： 自反 + 对称 的关系（不要求传递）。相容类、最大相容类（不能再加入其他元素）。由覆盖可产生相容关系。

二、偏序关系【简单应用，重点】

  1. 偏序关系 ： 自反 + 反对称 + 传递 ，记为 ≤；称 <A, ≤> 为 偏序集 。 典型：集合的包含 ⊆、数的 ≤、整除 |。
  2. 拟序（严格偏序） ： 反自反 + 传递 （必反对称），记 <，如严格小于、真包含。
  3. 全序（线序） ：偏序集中 任意两个元素都可比 （∀x,y，x≤y 或 y≤x）。
  4. 良序 ：每个非空子集都有最小元的偏序（良序一定是全序）。
  5. 可比与盖住 ：x≤y 或 y≤x 称可比；若 x<y 且不存在 z 使 x<z<y，称 y 盖住 x （y 是 x 的直接后继）。

  3. 省略箭头，约定 小元素画在下方、大元素画在上方 （边从下往上指）。

最大下界（下确界 inf）B 的所有下界中最大者至多一个

关系：最大（小）元一定是极大（小）元且属于 B；最大元必是最小上界。有限偏序集一定有极大元和极小元，但不一定有最大（小）元。

5.4 函数

一、函数的定义【领会】

  1. 函数（映射）f：A→B 是一种特殊关系，满足：

    • 存在性 ：dom f = A，即 A 中 每个 x 都有对应；
    • 唯一性 ：每个 x 只对应 唯一 的 y（不能一对多）。

    记 y=f(x)，x 称自变量（原像），y 称函数值（像）。

  2. A 称 定义域 ，B 称 陪域（目标集） ，ran f=f(A)={f(x)|x∈A}⊆B 称 值域 。

  3. 函数是关系但关系不一定是函数；判断关系是否为函数就查"处处有定义 + 单值”。

二、三种特殊函数（必会判别）【简单应用】

设 f：A→B：

  1. 单射（入射/injection） ：不同自变量对应不同函数值，即 x₁≠x₂ ⇒ f(x₁)≠f(x₂)（等价 f(x₁)=f(x₂)⇒x₁=x₂）。
  2. 满射（surjection） ： 值域 = 陪域 ，ran f=B，即 B 中每个元素都有原像。
  3. 双射（一一对应/bijection） ： 既单射又满射 。
  4. 有限集：f：A→B 为单射 ⇒ |A|≤|B|；满射 ⇒ |A|≥|B|；双射 ⇒ |A|=|B|。
  5. 常函数（所有 x 映到同一值）、恒等函数 I_A（I_A(x)=x，是双射）。

三、复合函数与反函数【领会】

  1. 复合函数 g∘f ：f：A→B，g：B→C，则 (g∘f)(x)=g(f(x))，A→C。
    • 若 f、g 都单射，则 g∘f 单射；都满射则 g∘f 满射；都双射则 g∘f 双射。
    • 复合满足结合律，一般不满足交换律。
  2. 反函数（逆函数）f⁻¹ ： 只有双射函数才有反函数 （双射可逆）。
    • f⁻¹∘f = I_A，f∘f⁻¹ = I_B；(f⁻¹)⁻¹=f；(g∘f)⁻¹=f⁻¹∘g⁻¹。
  3. 基数与可数：双射用于比较集合"大小”；与自然数集或其有限子集一一对应的为可数集（了解）。

★ 本章解题方法速查

  1. 判关系性质 ：三法任选——定义逐条验、关系矩阵看特征、关系图看边。建议矩阵/图与定义互验。
  2. 复合运算 ：先按定义找"中间桥梁 y”，或用关系矩阵布尔乘法 MR∘S=M_S⊙M_R。
  3. 闭包 ：自反补自环（∪I_A）、对称补反向边（∪R⁻¹）、传递用 R∪R²∪…∪Rⁿ。
  4. 等价关系 ：验三性质 → 写等价类 → 得商集/划分；模 n 同余有 n 类。
  5. 哈斯图 ：去自环、去传递边、箭头向上；据此读极大（小）/最大（小）元、上下确界。
  6. 判函数类型 ：先确认是函数，再看是否一对一（单射）、是否覆盖 B（满射）。

四、证明题

1. 逐条验证 R∩S：

  • 自反：R、S 自反，I_A⊆R 且 I_A⊆S，故 I_A⊆R∩S；
  • 对称：<x,y>∈R∩S 则 <x,y>∈R 且 ∈S，由二者对称得 <y,x>∈R 且 ∈S，故 ∈R∩S；
  • 传递：<x,y>,<y,z>∈R∩S，则分别在 R、S 中由传递性得 <x,z>∈R 且 ∈S，故 ∈R∩S。

三性质具备，R∩S 是等价关系。

2. (⇒) 设 R 对称。<x,y>∈R ⇒ <y,x>∈R ⇒ <x,y>∈R⁻¹，故 R⊆R⁻¹；反之 <x,y>∈R⁻¹ ⇒ <y,x>∈R ⇒（对称）<x,y>∈R，故 R⁻¹⊆R。所以 R=R⁻¹。 (⇐) 设 R=R⁻¹。<x,y>∈R ⇒ <x,y>∈R⁻¹ ⇒ <y,x>∈R，故 R 对称。证毕。

3. (⇒) 设 [a]=[b]。因 R 自反，b∈[b]=[a]，由等价类定义 aRb。 (⇐) 设 aRb。任取 x∈[a]，则 aRx；由对称 bRa，再由传递 bRa、aRx 得 bRx，即 x∈[b]，故 [a]⊆[b]；同理（bRa 及传递）可证 [b]⊆[a]。所以 [a]=[b]。证毕。

4. f、g 双射。

  • 单射 ：设 (g∘f)(x₁)=(g∘f)(x₂)，即 g(f(x₁))=g(f(x₂))；g 单射 ⇒ f(x₁)=f(x₂)；f 单射 ⇒ x₁=x₂。故 g∘f 单射。
  • 满射 ：任取 z∈C，g 满射 ∃y∈B 使 g(y)=z；f 满射 ∃x∈A 使 f(x)=y；于是 (g∘f)(x)=g(y)=z。故 g∘f 满射。
  • 既单又满，g∘f 是双射，其反函数为 (g∘f)⁻¹ = f⁻¹∘g⁻¹ 。

6.1 代数系统

一、n 元运算与封闭性【领会】

  1. n 元运算 ：从 Aⁿ 到 A 的映射 f：Aⁿ→A。常用一元（n=1，如求逆、取负）和二元（n=2，如 +、×）。
  2. 封闭性 ：若对任意 x,y∈A，x*y∈A（运算结果仍落在 A 中），称运算 * 在 A 上 封闭 。
  3. 二元运算可用 运算表（凯莱表） 表示：行、列分别列元素，交点填运算结果；由表可直接读封闭性、交换性、幺元、零元、逆元。

二、二元运算的常见性质【领会】

设 *、∘ 是 A 上二元运算：

  • 交换律 ：∀x,y，x*y = y*x（运算表关于主对角线对称）。
  • 结合律 ：∀x,y,z，(x*y)*z = x*(y*z)。
  • 幂等律 ：∀x，x*x = x（x 称幂等元；运算表主对角元等于行/列表头本身）。
  • 消去律 ：∀x,y,z，x*y=x*z ⇒ y=z（左消去），y*x=z*x ⇒ y=z（右消去）。
  • 分配律 ：* 对 ∘ 分配：x*(y∘z)=(x*y)∘(x*z) 及 (y∘z)*x=(y*x)∘(z*x)。
  • 吸收律 ：x*(x∘y)=x，x∘(x*y)=x。

三、特殊元素（必考识别）【简单应用】

设 * 是 A 上二元运算：

元素定义存在性/唯一性
幺元（单位元）e∀x， e*x = x*e = x若存在则 唯一
零元 θ∀x， θ*x = x*θ = θ若存在则 唯一
幂等元x*x = x可有多个（幺元、零元都是幂等元）
逆元 x⁻¹在有幺元 e 时，若 x*y=y*x=e，称 y 是 x 的逆元运算 可结合时逆元唯一
  • 左幺元 vs 右幺元 ：eₗ*x=x 称左幺元，x*eᵣ=x 称右幺元；若左、右幺元都存在则相等且为唯一幺元。零元同理。
  • 运算表识别口诀 ：
    • 幺元 e 所在 行与表头行相同、所在列与表头列相同 ；
    • 零元 θ 所在 行、列全部填 θ ；
    • x 的逆元：在 x 行与 x 列上找到结果为 e 的配对元素。
  • |A|>1 时， 幺元与零元不相等 （若 e=θ 则所有元素都等于它，集合只有一个元素）。

四、代数系统【领会】

  1. 代数系统（代数） ：一个非空集合 A 连同其上若干个封闭的 n 元运算 f₁,…,fₖ，记 <A, f₁,…,fₖ>（可含特异元素如 0、1）。
  2. 同类型代数系统 ：运算个数、各运算元数相同。
  3. 子代数 ：B⊆A，B 对 A 的所有运算封闭且含相同特异元素，则 <B,…> 是 <A,…> 的子代数。

6.2 群与半群（核心）

一、四级结构（条件逐级加强，必背）【简单应用】

设 <S, >， 是二元运算：

即群的四条公理： ①封闭性；②结合律；③存在幺元；④每个元素有逆元 。

  • 交换群（阿贝尔群 Abel 群） ：群 + 运算还满足 交换律 。
  • 有限群 / 无限群 ：群的 阶 |G| 指元素个数；有限则称有限群。
  • 举例：

    • 模 n 剩余类加法 <Zₙ,⊕> 是有限交换群（n 阶）。

二、群的基本性质（会直接用于判定/填空）【领会】

设 <G,*> 是群，幺元 e：

  1. 幺元唯一，每个元素的逆元唯一。
  2. 群中满足消去律 ：a*b=a*c ⇒ b=c。
  3. 方程 a*x=b 与 y*a=b 都有唯一解 （x=a⁻¹*b，y=b*a⁻¹）。
  4. (a*b)⁻¹ = b⁻¹*a⁻¹ （穿脱原则，逆的乘积颠倒次序）；(a⁻¹)⁻¹=a。
  5. 除 平凡群（仅含一个元素）外，群中没有零元 （零元无逆元，与"每元有逆"矛盾）。
  6. 群中只有幺元是幂等元：x*x=x ⇒ x=e（两边乘 x⁻¹）。
  7. 有限代数系统中，若运算封闭、结合且满足消去律，则它是群（有限群的一种判别）。

三、子群【领会】

  1. 子群 ：H⊆G，H 对群运算 * 自身也构成群，记 H≤G。{e} 与 G 本身是平凡子群。
  2. 子群判别条件 （非空子集 H⊆G 是子群）常用等价形式：
    • H 非空，且 ①对 * 封闭（a,b∈H⇒ab∈H）；②对求逆封闭（a∈H⇒a⁻¹∈H）；
    • 一条式判别 ：H 非空，且 ∀a,b∈H， a*b⁻¹∈H （则 H 是子群）。
    • 有限子集判别：有限非空 H 对运算封闭即是子群（有限+封闭+结合+消去保证逆元存在）。
  3. 循环群 ：若存在 a∈G 使 G 中每个元素都是 a 的幂（aⁿ），称 G 为循环群，a 为生成元。循环群一定是交换群。

6.3 环与域

一、环【识记/领会】

  1. 环的定义 ：代数系统 <R, +, ·> 满足：
    • <R, +> 是交换群（阿贝尔群） （加法封闭、结合、交换、有加法幺元 0、每元有加法逆元 −a）；
    • <R, ·> 是半群 （乘法封闭、结合）；
    • 乘法对加法满足分配律 ：a·(b+c)=a·b+a·c，(b+c)·a=b·a+c·a。
  2. 环的基本性质：
    • 加法幺元记 0，a 的加法逆元记 −a，减法 a−b=a+(−b)；
    • a·0 = 0·a = 0 ；
    • (−a)·b = a·(−b) = −(a·b)；(−a)·(−b)=a·b。
    • 环中乘法 不一定交换、不一定有单位元、非零元不一定有逆元 。

二、几种特殊环【识记】

类型在环基础上额外满足
交换环乘法满足交换律 a·b=b·a
含幺环乘法存在单位元 1（1·a=a·1=a）
无零因子环若 a·b=0 则 a=0 或 b=0（没有非零的零因子）
整环含幺 + 交换 + 无零因子 的环

零因子 ：a≠0、b≠0 但 a·b=0，称 a 为左零因子、b 为右零因子。模 n 环中 n 为合数时存在零因子。

三、域【识记】

  1. 域的定义 ：代数系统 <F, +, ·> 满足：
    • <F, +> 是交换群；
    • <F∖{0}, ·> 是交换群 （即乘法交换、有单位元 1、 每个非零元都有乘法逆元 ）；
    • 乘法对加法分配。
  2. 关系： 域一定是整环 （域中无零因子）； 有限整环一定是域 。
  3. 典型例子：
    • <Z,+,·> 整数集：是 整环但不是域 （2 等非零元无整数乘法逆元）；
    • <Q,+,·>、<R,+,·>、<C,+,·> 都是 域 ；
    • 模 n 剩余类环 <Zₙ,⊕,⊗>：当且仅当 n 为素数时是域 （此时每个非零剩余类都与 n 互素，有乘法逆元）。

四、判别题标准答题模板（证明整环/域）【简单应用】

证明 <R,+,·> 是整环，按顺序逐条验证：

  1. <R,+> 封闭、结合、交换、有零元 0、每元有负元（即加法交换群）；
  2. <R,·> 封闭、结合（即乘法半群）；
  3. 乘法交换（交换环）；
  4. 乘法有单位元 1（含幺环）；
  5. 乘法对加法左右分配；
  6. 无零因子：ab=0 ⇒ a=0 或 b=0。

（域再加：每个非零元有乘法逆元。）

★ 本章解题方法速查

  1. 看运算表 ：封闭看结果是否全在集合内；交换看是否对角对称；幺元找"行列表头复制行/列”；零元找"全填同一元素"的行列；逆元找 e 的配对。
  2. 判半群/独异点/群 ：封闭→结合→幺元→逆元，逐级打勾，缺哪级就停在哪级。
  3. 结合律验证 ：运算表无法一眼看出，需对所有三元组（或题目指定）验证 (ab)c=a(bc)；常见数的 +、× 可直接引用。
  4. 判子群 首选 a*b⁻¹∈H 一条式。
  5. 判环/整环/域 ：先确认加法交换群，再乘法半群，再分配，再按整环（交换+含幺+无零因子）、域（非零元有逆）加码。
  6. 记牢典型反例：<Z,·> 独异点非群；<Z,+,·> 整环非域；Zₙ 素数为域、合数有零因子。

第 7 章 格与布尔代数

考核要求 ：格的基本概念〔领会〕；分配格与有补格〔领会〕；布尔代数〔识记〕 本章重点 = 难点 ：格、分配格、有补格的概念及性质判别

7.1 格的基本概念

一、格的偏序定义【领会】

  1. 格 ：设 <A, ≤> 是偏序集，若对 任意两个元素 a,b∈A ，子集 {a,b} 在 A 中都有

    • 最大下界（下确界） ，记 inf{a,b} = a∧b （交运算）；
    • 最小上界（上确界） ，记 sup{a,b} = a∨b （并运算）；

    则称 <A, ≤> 是一个 格 。

  2. 由格可诱导代数系统 <A, ∧, ∨> ：a∧b 为 a、b 的最大下界，a∨b 为最小上界。

  3. “任意两个元素有上下确界"等价于"任意有限子集有上下确界”（但不要求任意无限子集都有）。

  4. 常见格 ：

    • 幂集格 <P(S), ⊆> ：A∧B=A∩B，A∨B=A∪B；
    • 整除格 <Z⁺, |> （正整数整除关系）：a∧b= gcd(a,b) （最大公约数），a∨b= lcm(a,b) （最小公倍数）；
    • 任意 全序集（链） 都是格：a∧b=min(a,b)，a∨b=max(a,b)。

  5. 判格方法 ：画哈斯图，检查每一对元素是否都有唯一的最大下界和最小上界；若有某对元素没有最小上界（出现两个互不可比的"最小上界候选”）则不是格。

二、对偶原理【识记】

  1. 对偶命题 ：把命题 P 中的 ≤ 与 ≥、∧ 与 ∨ 互换，得到对偶命题 P′。
  2. 格的对偶原理 ：若命题 P 对一切格为真，则其对偶命题 P′ 也对一切格为真。（证明一个即可得到另一个）

三、格的基本性质（格中算律）【领会】

设 <A,≤> 是格，对任意 a,b,c∈A：

  1. 基本序关系 ：a ≤ a∨b，b ≤ a∨b；a∧b ≤ a，a∧b ≤ b。
  2. 交换律 ：a∨b=b∨a；a∧b=b∧a。
  3. 结合律 ：a∨(b∨c)=(a∨b)∨c；a∧(b∧c)=(a∧b)∧c。
  4. 幂等律 ：a∨a=a；a∧a=a。
  5. 吸收律 ：a∨(a∧b)=a；a∧(a∨b)=a。
  6. 保序性 ：若 a≤b，则 a∧c≤b∧c 且 a∨c≤b∨c；若 a≤b 且 c≤d，则 a∨c≤b∨d 且 a∧c≤b∧d。
  7. a≤b ⇔ a∧b=a ⇔ a∨b=b（与集合包含刻画平行）。

注意：格 不一定满足分配律 ，也不一定有补元——这正是下一节两类特殊格的内容。

四、格的代数定义与子格【领会】

  1. 格的等价（代数）定义 ：若代数系统 <A,∧,∨> 的两个二元运算满足 交换律、结合律、吸收律 （吸收律可推出幂等律），则 A 上可定义偏序使它成为格。
  2. 子格 ：设 <L,∧,∨> 是格，S 是 L 的非空子集，若 S 关于 ∧、∨ 封闭 ，则 <S,∧,∨> 是 L 的子格。
    • 注意：S 自身可能是格但不是原子格的子格（若某两元素在 S 中的上/下确界与在 L 中不同则不封闭）。

7.2 分配格与有补格

一、分配格【领会】

  1. 定义 ：格 <A,∧,∨> 中，若对任意 a,b,c 满足

    • a∧(b∨c) = (a∧b)∨(a∧c)；
    • a∨(b∧c) = (a∨b)∧(a∨c)；

    则称其为 分配格 。（两式等价，成立其一即可）

  2. 两个最重要的非分配格（必须认识） ：

    • 钻石格 M₅（五角格之外的五元格） ：形如 0 之上三个互不可比元素 a,b,c、再上为 1；
    • 五角格 N₅ ：五个元素构成的链状带一侧支的格。
    • 钻石格反例：b∧(c∨d)=b∧1=b，而 (b∧c)∨(b∧d)=0∨0=0，分配律失败。

  3. 判定定理（定理7.7） ： 格 L 是分配格，当且仅当 L 中不含与钻石格 M₅ 或五角格 N₅ 同构的子格。

  4. 推论 ：

    • 任何少于 5 个元素的格都是分配格 ；
    • 任意一条链（全序格）都是分配格 ；
    • 幂集格、整除格都是分配格。

  5. 格同态/同构 ：保持 ∧、∨ 的映射 f（f(a∧b)=f(a)∧f(b)，f(a∨b)=f(a)∨f(b)）；双射时为格同构。

二、有界格与补元【领会】

  1. 全下界 0 ：A 中存在元素，比所有元素都小（∀x，0≤x）； 全上界 1 ：比所有元素都大。二者若存在必 唯一 。
  2. 有界格 ：同时存在全下界 0 和全上界 1 的格，记 <A,∧,∨,0,1>。
    • 任何有限格都是有界格 （所有元素之∧为0、之∨为1）；幂集格中 ∅ 为 0、全集为 1。
  3. 补元 ：在有界格中，若 a∨b= 1 且 a∧b= 0 ，则称 b 是 a 的补元，记 a′（或 ā）。
    • 互补是相互的（b 是 a 的补元，则 a 是 b 的补元）；
    • 0 与 1 恒互补 ；
    • 一个元素可能 没有补元、有一个补元、或有多个补元 （钻石格中中间三元互为补元，有两个补元）。
  4. 补元唯一性定理（定理7.8） ：在 有界分配格 中，若某元素存在补元，则其补元 唯一 。
  5. 有补格 ：有界格中 每个元素都有补元 ，称有补格。

三、五类格关系小结

格 →（满足分配律）分配格；格 →（有0有1）有界格；有界格 →（每元有补）有补格； 分配格 + 有补格 = 布尔代数 。

7.3 布尔代数

一、定义【识记】

  1. 布尔代数（布尔格） ：一个 有补的分配格 ，记 <B,∧,∨,′,0,1>。
  2. 因布尔代数是有补分配格，由补元唯一性定理， 每个元素都有唯一补元 a′ ；求补 ′ 是一元运算。
  3. 常见布尔代数 ：
    • 二值布尔代数 B={0,1}（∧=与、∨=或、′=非）；
    • 集合代数 <P(S),∩,∪,~,∅,S>；
    • 命题代数 （命题集合上 ∧、∨、¬，矛盾式为0、重言式为1）；
    • Bⁿ（n 元 0/1 向量） ：按分量做与、或、非，构成布尔代数。

二、布尔代数的公理（Huntington 公理，定理7.9）【识记】

<B,∧,∨,′,0,1>（B 至少两元素）满足：

  • (H1) 交换律 ：a∧b=b∧a，a∨b=b∨a；
  • (H2) 分配律 ：a∧(b∨c)=(a∧b)∨(a∧c)，a∨(b∧c)=(a∨b)∧(a∨c)；
  • (H3) 同一律 ：a∨0=a，a∧1=a（0 是∨幺元，1 是∧幺元）；
  • (H4) 补元律 ：a∧a′=0，a∨a′=1。

（由这四条可推出结合律、吸收律等。）

三、布尔代数重要性质【领会】

  1. 双重否定律 ：(a′)′ = a。
  2. 德摩根律 ： (a∧b)′ = a′∨b′；(a∨b)′ = a′∧b′ 。
  3. 0、1 互补：0′=1，1′=0。
  4. 1 是 ∧ 的幺元、∨ 的零元；0 是 ∨ 的幺元、∧ 的零元。
  5. 布尔代数中 a∨(a′∧b)=a∨b，a∧(a′∨b)=a∧b（消补律，常考填空/化简）。

★ 本章解题方法速查

  1. 判格 ：画哈斯图，逐对元素确认都有唯一上确界（两元素向上路径的最低汇合点）和下确界。
  2. 整除格求上下确界 ：∧=gcd，∨=lcm。
  3. 判分配格 ：数元素（<5 必分配）、看是否链（链必分配）、找是否藏钻石格 M₅ 或五角格 N₅ 子格。
  4. 求补元 ：在有界格中对每个 a 找满足 a∨b=1 且 a∧b=0 的 b；分配格中至多一个。
  5. 判有补格 ：逐元素确认都有补元（0↔1 必互补）。
  6. 布尔代数化简 ：用交换、分配、吸收、补元、德摩根、双重否定，与命题逻辑/集合运算完全同构。

1. 设有界分配格 L，令 S={x∈L | x 有补元}。0、1∈S（互补），S 非空。需证 S 对 ∧、∨ 封闭。 任取 a,b∈S，补元分别为 a′、b′。令 c=a∧b，验证 a′∨b′ 是 c 的补元： c∧(a′∨b′)=(a∧b∧a′)∨(a∧b∧b′)=0∨0=0（分配律、补元律）； c∨(a′∨b′)=(a∨a′∨b′)∧(b∨a′∨b′)=1∧1=1。 故 a∧b 有补元 a′∨b′，属于 S。同理 a∨b 有补元 a′∧b′，属于 S。S 对 ∧、∨ 封闭，是子格。证毕。

2. 设 L 是分配格，S 是 L 的子格。对任意 a,b,c∈S，因 S⊆L 且 S 对 ∧、∨ 封闭，分配等式 a∧(b∨c)=(a∧b)∨(a∧c)、a∨(b∧c)=(a∨b)∧(a∨c) 在 L 中成立，且等式两边元素都在 S 中，故在 S 中同样成立。所以 S 是分配格。证毕。

第 8 章 图

考核要求 ：图的基本概念〔识记〕；图的连通性〔领会〕；图的表示〔简单应用〕 本章重点 ：图的定义与性质、判别方法、邻接矩阵表示法 本章难点 ：路径（可达性）矩阵

8.1 图的基本概念

一、图的基本术语【识记】

  1. 图 G=(V,E) ：V 是非空有限 顶点（结点）集 ，E 是 边集 ，每条边连接 V 中一对顶点。|V| 为顶点数，|E| 为边数。
  2. 无向边 (u,v) ：不限方向，(u,v)=(v,u)； 有向边（弧）<u,v> ：u 称 弧尾（起点） ，v 称 弧头（终点） ，<u,v>≠<v,u>。
    • 全含无向边称 无向图 ，全含弧称 有向图 。
  3. 多重边（平行边） ：两顶点间多于一条的边（重数=边的条数）； 环（自环） ：起点终点相同的边。
    • 多重图 ：含多重边或环； 简单图 ：不含多重边和环。
    • 注意：有向图中 <u,v> 与 <v,u> 是两条不同的边，不算平行边。
  4. n 阶图 ：|V|=n； 零图 ：E=∅（无边）； 平凡图 ：仅一个顶点（必为零图）；边少称稀疏图，边多称稠密图。
  5. 端点、邻接点（两点被同一条边连接）、边与顶点相关联。

二、顶点的度（核心，握手定理）【简单应用】

  1. 无向图 ：deg(v)=与 v 关联的边数； 环使其端点度数加 2 。
    • deg(v)=0 称 孤立点 ；deg(v)=1 称 悬挂点 ；
    • 度数为奇称 奇点 ，为偶称 偶点 。
  2. 握手定理（定理8.1） ： Σv∈V deg(v) = 2|E| （所有顶点度数之和等于边数两倍）。
  3. 定理8.2 ： 任何图中奇点个数必为偶数 。
  4. 有向图 ：
    • 出度 deg⁺(v) ：以 v 为起点的弧数； 入度 deg⁻(v) ：以 v 为终点的弧数；deg(v)=deg⁺+deg⁻；
    • 定理8.3 ： Σdeg⁺(v) = Σdeg⁻(v) = |E| （所有出度之和=所有入度之和=边数）。

三、完全图、补图、正则图、子图【识记/领会】

  1. 无向完全图 Kₙ ：n 个顶点的简单无向图，每对不同顶点间都有边。
    • 边数 = C(n,2) = n(n−1)/2 ；每点度 n−1（是 (n−1)-正则图）。
  2. 有向完全图 ：每对顶点间两个方向都有弧，边数 = n(n−1) 。
  3. 补图 G̅ ：以 V 为顶点集、以"所有属于 Kₙ 但不属于 G 的边"为边集。G 与 G̅ 的边数之和 = n(n−1)/2。
  4. 自补图 ：G 与 G̅ 同构（G≅G̅）。 必要条件：Kₙ 的边数 n(n−1)/2 为偶数 （否则无法平分）。
    • n=3：3 条边为奇数，无 3 顶点自补图；n=6：15 为奇数，无 6 顶点自补图；n=4、5 存在。
  5. 最大度 Δ(G)=max deg(v) ； 最小度 δ(G)=min deg(v) 。
  6. k-正则图 ：每个顶点度数都为 k。Kₙ 是 (n−1)-正则图。
  7. 子图 ：G′=(V′,E′)，V′⊆V 且 E′⊆E。 生成子图（支撑子图） ：V′=V（含全部顶点）的子图。
  8. 图同构 G₁≅G₂ ：两图顶点间存在一一对应（双射），且保持邻接关系与边的重数。直观：顶点可重新标号使两图完全相同。

8.2 图的连通性

一、通路与回路【领会】

  1. 通路（路径/路） ：顶点与边的交替序列 v₀e₁v₁e₂…eₙvₙ；v₀ 起点、vₙ 终点； 长度 = 边数 n 。起点=终点称 回路（圈） 。
  2. 分类：
    • 简单通路/简单回路 ：所有 边 互不相同（边不重复，顶点可重复）；
    • 初级通路（路径）/初级回路（圈） ：所有 顶点 互不相同（起点终点可相同）；初级必简单，反之不然。
  3. 定理8.4 ：无向图中若每个顶点度数 ≥2，则必含一条初级回路。
  4. 定理8.5 ：n 阶图中若 u 到 v（u≠v）有通路，则必有一条 长度 ≤ n−1 的通路（进而有长度 ≤ n−1 的初级路）。

二、连通性【领会】

  1. 连通 ：无向图中两顶点间存在通路。连通关系是顶点集上的 等价关系 （自反、对称、传递）。
  2. 连通图 ：任意两顶点都连通；否则不连通。
  3. 连通分支（连通分量） ：按连通关系对 V 划分所得的极大连通子图，个数记 p(G) （或 w(G)）。连通图 p(G)=1。
  4. 有向图的连通性 ：
    • 可达 ：从 u 到 v 有有向路（可达关系自反、传递，但 不一定对称 ，不是等价关系）；
    • 强连通 ：任意两顶点 相互可达 ；
    • 单侧连通 ：任意一对顶点至少有一个方向可达；
    • 弱连通 ：忽略边的方向（看成无向图）后连通。
    • 强弱关系：强连通 ⇒ 单侧连通 ⇒ 弱连通。
  5. 割点 ：连通无向图中删去该顶点（及关联边）后图不再连通。
  6. 点割集 ：删去该顶点集（及其真子集不破坏连通）后图不连通的最小顶点集。
  7. 割边（桥） ：删去该边后图不再连通的边。
  8. 边割集 ：删去后使图不连通的最小边集。 > 点割集 V′ 使 G−V′ 恰有 2 个连通分量；边割集同理。

8.3 图的表示（邻接矩阵，必考计算）

一、邻接矩阵【简单应用】

  1. 定义 ：设 V={v₁,…,vₙ}，邻接矩阵 M(G)=(mᵢⱼ)ₙₓₙ ， mᵢⱼ = 从 vᵢ 到 vⱼ 的边的条数 （简单图中为 0 或 1，是布尔矩阵）。
  2. 无向图 ：M 是 对称矩阵 （mᵢⱼ=mⱼᵢ）； 有向图一般不对称 。
  3. 由矩阵求度 ：
    • 无向图：顶点 vᵢ 的度 = 第 i 行 （或第 i 列）非零元素个数（环在对角线上计 2，需注意）；
    • 有向图：第 i 行 非零数 = 出度 deg⁺(vᵢ)，第 i 列 非零数 = 入度 deg⁻(vᵢ)。
  4. 给邻接矩阵要能画回图，给图要能写矩阵（行列均按固定顶点次序）。

二、邻接矩阵的幂——数通路【简单应用】

定理8.6 ： Mᵏ 中的元素 (Mᵏ)ᵢⱼ 等于从 vᵢ 到 vⱼ 长度恰为 k 的通路条数。

  • 对角线元素 (Mᵏ)ᵢᵢ 是 vᵢ 到自身长度为 k 的回路数；
  • M、M²、…、Mᵏ 中 (i,j) 元素之和 = vᵢ 到 vⱼ 长度不超过 k 的通路总数。
  • 矩阵乘法用普通整数加法、乘法（不是布尔运算），结果是通路"条数”。

三、可达性矩阵（路径矩阵）【领会，难点】

  1. 定义 ：P(G)=(pᵢⱼ)， pᵢⱼ=1 当且仅当 vᵢ 到 vⱼ 至少存在一条通路 （否则 0）；对角线通常取 1（每点到自身可达）。
  2. 求法 ：令 Bₙ = M + M² + … + Mⁿ ，再把 Bₙ 中所有 非零元素改为 1 、零仍为 0，即得可达性矩阵 P。
  3. 应用：
    • P 全为 1（除按约定的对角）⇔ 任意两点可达：无向图即连通图，有向图即强连通；
    • 可由 P 判断连通分支数、各点是否在回路上（pᵢᵢ 相关）。
  4. 该概念可推广到有向图。

9.1 欧拉图与哈密顿图

一、欧拉图（一笔画）【简单应用】

  1. 欧拉通路 ：连通图中经过 每条边一次且仅一次 的通路； 欧拉回路 ：起点=终点的欧拉通路。
  2. 欧拉图 ：具有欧拉回路的图； 半欧拉图 ：有欧拉通路但无欧拉回路。
  3. 无向图判别（必背） ：
    • G 是欧拉图 ⇔ G 连通且没有奇点（所有顶点都是偶点） ；
    • G 有欧拉通路（半欧拉图）⇔ G 连通且恰有 2 个奇点 （通路从一个奇点出发、到另一个奇点结束）；
    • 奇点个数为 0 或 2 才能一笔画；奇点超过 2 个不能一笔画（所需笔画数=奇点数/2）。
  4. 有向图判别 ：
    • 有欧拉 回路 ⇔ 图（基图）连通且 每个顶点入度=出度 ；
    • 有欧拉 通路 ⇔ 连通，除两个顶点外入度=出度，其中一个 出度比入度大1（起点） 、另一个 入度比出度大1（终点） 。
  5. 求欧拉回路方法：从任一点出发找回路 C，删 C 的边，在剩余图中找与 C 共点的回路并在公共点处拼接，直到用尽所有边。

二、哈密顿图【简单应用】

  1. 哈密顿路（H-路） ：经过 每个顶点一次且仅一次 的路； 哈密顿回路（H-回路） ：经过每个顶点一次且仅一次的回路； 哈密顿图 ：含哈密顿回路的图。
  2. 与欧拉图区别 ：欧拉要求"边"不重复，哈密顿要求"顶点"不重复。
  3. 必要条件（定理9.4，用来证明"不是"哈密顿图） ： 若 G 有哈密顿回路，则对顶点集的 任意非空子集 S ，都有 p(G−S) ≤ |S| （删去 S 后连通分支数不超过 |S|）。
    • 若找到某个 S 使 p(G−S)>|S|，则 G 一定不是 哈密顿图。
    • 注意该条件 只是必要不充分 ：彼得森图满足它却不是哈密顿图。
  4. 充分条件（定理9.5、9.6，用来证明"是”） ：
    • n 个顶点的简单图，若 任意两顶点度数之和 ≥ n−1 ，则存在哈密顿路；
    • 若 任意两顶点度数之和 ≥ n ，则存在哈密顿回路（是哈密顿图）。
    • 充分条件不必要（不满足也可能是哈密顿图，如 Cₙ 每点度2，2+2=4<n 但它是哈密顿图）。
  5. 快速排除 ： 含度数为 1 的顶点的图必不是哈密顿图 （哈密顿回路中每点恰关联回路两条边）。
  6. 典型应用——圆桌入座问题 ：把人作顶点、两人能相邻（有共同语言/是朋友）连边，安排座位 = 求一条哈密顿回路。“每人至少有 n/2 个朋友"型条件常用度和充分条件判定。

9.2 平面图

一、基本概念【领会】

  1. 平面图（可平面图） ：能画在平面上，使边 仅在端点处相交 的图。
    • 平面图的子图都是平面图；非平面图的母图都是非平面图。
  2. 面 ：平面图的边把平面分成的区域；面积无限的称 无限面（外部面） ，有限的称 有限面（内部面） 。
  3. 面的次数 deg(R) ：包围该面的边界回路长度（桥在所属面的次数中计 2）。
  4. 定理9.7 ：连通平面图中， 所有面次数之和 = 2|E| （每条边给面次数贡献2）。

二、欧拉公式（必考）【简单应用】

定理9.8（欧拉公式） ：连通平面图有 n 个顶点、m 条边、r 个面 ，则 n − m + r = 2 。

  • 变形：r = m − n + 2。
  • 对有 w 个连通分量的平面图推广为 n − m + r = 1 + w。

重要推论（判别非平面图） ：

  1. 定理9.9 ：n≥3 的简单连通平面图， m ≤ 3n − 6 。
  2. 定理9.10 ：n≥3、 不含长度为3的回路（无三角形） 的简单连通平面图， m ≤ 2n − 4 。
  3. 用法：算出 n、m，若违反上述不等式，则 一定不是平面图 。

三、两个基本非平面图与库拉图斯基定理【领会】

  1. K₅（5 顶点完全图） ：n=5，m=10；3n−6=9，10>9，违反 m≤3n−6， 非平面 。
  2. K₃,₃（完全二部图） ：n=6，m=9，无三角形；2n−4=8，9>8，违反 m≤2n−4， 非平面 。
  3. 同胚 ：两图同构，或经过反复 插入/消去 2 度顶点 后同构。
  4. 库拉图斯基定理（定理9.11） ： G 是平面图 ⇔ G 不含与 K₅ 同胚的子图，也不含与 K₃,₃ 同胚的子图。

9.3 树及其遍历（综合应用，分值高）

一、树的基本概念与性质【综合应用】

  1. 树（自由树） ： 连通且无回路 的无向图。树必是简单图（无环、无平行边）。
    • 叶结点（叶子） ：度数为 1 的结点； 分支点（内点） ：度数 >1 的结点。
    • 森林 ：无回路的无向图（每个连通分量都是树）。
  2. 树的等价刻画（定理9.12，六条等价） ：T 有 n 个结点， (1) T 是树； (2) T 无回路，且任意两顶点间有 唯一 一条路； (3) T 无回路，且有 n−1 条边 ； (4) T 连通，且有 n−1 条边 ； (5) T 连通，但删去任一条边就不再连通（ 每条边都是桥 ）； (6) T 无回路，但增加任一条边恰产生唯一一个回路。
  3. 核心数量关系 ： n 个结点的树恰有 n−1 条边 ；连通图至少需要 n−1 条边。
  4. 定理9.13 ：n≥2 的树 至少有 2 个叶结点 。
  5. 推论9.1（森林） ：G 有 n 个顶点、e 条边、w 个连通分量，则 G 是森林 ⇔ e = n − w 。
  6. 定理9.14 ：树的每个分支结点都是割点。

二、生成树与最小生成树【简单应用】

  1. 生成树（支撑树） ：连通图 G 的生成子图 T 若是一棵树。T 中的边称 树枝 ，G 中不在 T 的边称 弦 ；弦构成的子图称 余树 。
    • n 个顶点的连通图，其生成树有 n−1 条树枝，弦数 = |E|−(n−1)。
  2. 定理9.15 ： 任何连通图至少有一棵生成树 。非树的连通图生成树不唯一。
  3. 破圈法求生成树 ：反复找回路并删去回路中任一条边（保持连通），直到无回路，即得生成树。
  4. 带权图与最小生成树 ：
    • 边带权 w(e)；生成树 T 的权 W(T)=各树枝权值之和；权最小的生成树称 最小生成树 。
  5. Kruskal（克鲁斯卡尔）算法（避圈法） ：
    • 把所有边 按权值从小到大 排序；依次考察， 若该边两个端点尚不在同一连通分量中（加入后不形成圈）就选入 ，否则舍弃；
    • 直到选出 n−1 条边 （所有顶点连通）为止，所得即最小生成树（定理9.16）。
    • 等权边次序不同可能得到不同的最小生成树，但最小权值相同。

三、有根树与二叉树【综合应用】

  1. 有向树 ：忽略边方向后是树的有向图。 有根树 ：恰有一个入度为0的结点（ 根 ），其余结点入度均为1。
    • 出度为0称叶；出度>0称分支点（内点）。父/子、兄弟、祖先/子孙、子树。
    • 层次 ：根在第0层，子结点层次+1； 深度 =最大层次； 高度 =深度+1。
  2. m 叉树 ：每个结点出度 ≤m； 完全 m 叉树 ：每个结点出度恰为 m 或 0； 正则 m 叉树 ：完全 m 叉树且所有叶子在同一层。
  3. 二叉树 ：m=2，子结点分 左子结点、右子结点 （有序，左右不可互换），对应左子树、右子树；共 5 种基本形态（空、仅根、根+左、根+右、根+左右）。
  4. 完全 m 叉树数量公式（定理9.17，必考） ：设叶结点数 t 、分支结点数 i ，则 (m−1)i = t − 1 ，即 t = (m−1)i + 1 ，总结点数 n = t+i = mi+1。
    • 二叉树（m=2） ： t = i + 1 （叶子比分支点多1），n=2i+1，故 t=(n+1)/2、i=(n−1)/2 （完全二叉树总结点数为奇数）。
  5. 表达式树：运算符为分支点、操作数为叶子。

四、二叉树的三种遍历（必考）【综合应用】

二叉树 = 根 + 左子树 + 右子树，三部分访问顺序不同：

遍历方式顺序助记
先序（前序）遍历根 → 左子树 → 右子树根左右（DLR）
中序遍历左子树 → 根 → 右子树左根右（LDR）
后序遍历左子树 → 右子树 → 根左右根（LRD）
  • 对表达式树： 先序得前缀式（波兰式） 、 中序得常规中缀式 （忽略括号）、 后序得后缀式（逆波兰式） ；三种遍历中操作数（叶子）的相对次序不变。
  • 一般树有先序（根→依次各子树）和后序（依次各子树→根）两种遍历。

6. 设二叉树中：n₀ 为叶子（度0）数，n₁ 为度1结点数，n₂ 为度2结点数。总结点 n=n₀+n₁+n₂。 边数为 n−1；从度数统计（无向树中边数也等于 Σdeg/2，二叉树中每点度=孩子数，根特殊处理）：用孩子数计数，总孩子数 = n₁+2n₂ = n−1（除根外每点恰有一个父结点）。 而 n−1=(n₀+n₁+n₂)−1，故 n₁+2n₂=n₀+n₁+n₂−1，化简得 n₂=n₀−1 ，即度为2的结点比叶子少1。证毕。

一、命题逻辑（第1、2章）

五大联结词真值要点

  • ¬P：与 P 相反。
  • P∧Q：全真才真。　P∨Q：有真则真（可兼或）。
  • ★ P→Q： 仅当 P=1、Q=0 时为假 ；前件假恒真（空真）。P→Q⇔¬P∨Q⇔¬Q→¬P。
  • P↔Q：同真同假才真。P↔Q⇔(P→Q)∧(Q→P)。
  • 优先级：¬ > ∧ > ∨ > → > ↔。

符号化

  • “只有 P 才 Q”=Q→P；“除非 P 否则 Q”=¬P→Q；“只要 P 就 Q”=P→Q。
  • 排斥或：(P∨Q)∧¬(P∧Q)。

必背等值式 ：双重否定 A⇔¬¬A；幂等 A∨A=A、A∧A=A；交换、结合； 分配 A∨(B∧C)=(A∨B)∧(A∨C)、A∧(B∨C)=(A∧B)∨(A∧C)； 吸收 A∨(A∧B)=A、A∧(A∨B)=A； 德摩根 ¬(A∨B)=¬A∧¬B、¬(A∧B)=¬A∨¬B； 零律 A∨T=T、A∧F=F；同一 A∨F=A、A∧T=A；补余 A∨¬A=T、A∧¬A=F。

必背蕴涵式 ：假言推理 A,A→B⇒B；拒取 ¬B,A→B⇒¬A； 析取三段论 ¬A,A∨B⇒B；假言三段论 A→B,B→C⇒A→C；化简 A∧B⇒A；附加 A⇒A∨B。

  14. 关系并运算 不保持传递性 （交运算保持五性质）。
  15. 复合 R∘S 是 先 S 后 R ，关系矩阵相乘次序 M_S⊙M_R，别乘反。
  16. 等价关系三性质缺一不可；偏序是"反对称"不是"反自反”。
  17. 极大元≠最大元：极大元可多个，最大元至多一个且要与所有元素可比。
  18. 单射看"是否一对一”，满射看"是否覆盖整个陪域 B”；双射才有反函数。
  19. <N,+>、<Z,·> 是独异点不是群（缺逆元）；<Q,×> 含0不是群。
  20. 阶>1的群没有零元；群的唯一幂等元是幺元。
  21. 整数环是整环不是域；Zₙ 合数时有零因子、不是域，素数才是域。
  22. 格未必分配、未必有补；判分配格找钻石格/五角格子格。
  23. 有界格中一个元素可能有多个补元（钻石格），但 有界分配格 中补元唯一。
  24. 握手定理中 环给度数贡献2 ；奇点必为偶数个。
  25. Mᵏ 用的是普通整数矩阵乘法（数通路条数），关系复合才用布尔乘法。
  26. 欧拉图看 边 是否走完（数奇点），哈密顿图看 顶点 是否走完，别混淆。
  27. p(G−S)≤|S| 只是哈密顿图的 必要 条件，满足也可能不是（彼得森图）。
  28. 用 m≤3n−6 判非平面时，先确认是 n≥3 简单连通平面图；K₃,₃ 要用 m≤2n−4（无三角形）。
  29. 树 n−1 条边是对 自由树/生成树 ；完全二叉树总结点数 n=2i+1 必为奇数。
  30. 二叉树左右子树 有序、不可交换 ；中序+先序/后序才能唯一确定一棵树，仅先序+后序不够。

附录 C　90+ 考场时间与答题规范

  1. 发卷后 ：先通览全卷，在草稿纸默写最怕忘的公式（主范式编码、欧拉公式、树的公式、群的层级），防止紧张遗忘。
  2. 选择题 ：概念辨析善用"举反例排除法"；真值/度数/计数题在草稿快速列表计算，不空题。
  3. 填空题 ：结果要最简（主范式写 mᵢ 编号、集合写花括号、矩阵写方括号对齐）；注意问的是"个数"还是"具体元素"。
  4. 简答题 ：
    • 真值表/关系矩阵/邻接矩阵：行列标齐，逐格计算，最后写一句结论；
    • 哈斯图、关系图、表达式树、生成树： 用尺作图 ，顶点标名、边不交叉；
    • 求范式/闭包/前束范式：写出关键中间步骤（按步骤给分）；
    • 最小生成树：列出选边与舍弃边及理由（成圈）。
  5. 证明题 ：开头写"证明"，代数系统/群环域题 逐条列公理打勾 ；图论题写清"必要性/充分性"两个方向；逻辑推理题用编号表格写依据（P/T/CP/UI/EI…）。
  6. 验算 ：度数之和必为偶数且=2|E|；矩阵行列和与度核对；范式成真+成假赋值总数应=2ⁿ；树边数=n−1。
  7. 不留白 ：证明题哪怕只证出部分条件、写出相关定义，也有步骤分。
