#Computer Organization and Architecture

一、存储器概述

1.1 存储器的分类

按存储介质

类型特点典型产品
半导体存储器速度快、体积小、功耗低RAM、ROM、Flash
磁表面存储器容量大、价格低、速度慢硬盘、磁带
光存储器容量大、可长期保存CD、DVD、蓝光

按存取方式

类型特点示例
随机存取（RAM）随机读写，时间与地址无关SRAM、DRAM
只读（ROM）只能读（或写入受限）Mask ROM、EPROM、EEPROM
顺序存取（SAM）按顺序访问磁带
直接存取（DAM）先定位区域再顺序查找磁盘

1.2 主存储器的组成

flowchart LR subgraph 主存["主存储器"] MAR["地址寄存器<br/>MAR"] --> 译码["地址译码器"] 译码 --> 存储体["存储体<br/>(Memory Array)"] 存储体 --> MDR["数据寄存器<br/>MDR"] 读写控制["读写控制电路"] --> 存储体 end CPU["CPU"] -->|地址| MAR MDR -->|数据| CPU CPU -->|读/写命令| 读写控制

读操作 ：CPU 送地址 → MAR → 译码 → 选中单元 → 数据读出到 MDR → CPU 取走 写操作 ：CPU 送地址到 MAR、数据到 MDR → 发写信号 → 写入指定单元

1.3 存储器层次化结构

flowchart TB A["寄存器<br/>速度最快 · 容量最小 · 价格最高"] B["L1 / L2 / L3 Cache<br/>(SRAM)"] C["主存<br/>(DRAM)"] D["SSD / HDD<br/>(磁盘)"] E["光盘 / 磁带<br/>速度最慢 · 容量最大 · 价格最低"] A --> B --> C --> D --> E style A fill:#ff6b6b,color:#fff style B fill:#ffa502,color:#fff style C fill:#2ed573,color:#fff style D fill:#1e90ff,color:#fff style E fill:#5352ed,color:#fff

设计思想 ：上层是下层的缓存，利用局部性原理，在速度、容量、价格之间取得平衡。

1.4 程序访问的局部性

类型含义示例
时间局部性最近访问的信息不久后再次访问循环体指令、循环变量
空间局部性访问某单元后，附近单元也会被访问顺序执行指令、数组遍历

  • 位扩展 ：增加数据宽度（多片并联数据线）

三、硬盘存储器

3.1 磁盘结构

flowchart TB subgraph 磁盘["磁盘物理结构"] 盘片["盘片（多个同轴）"] 磁道["磁道（同心圆）"] 扇区["扇区（磁道分段）"] 柱面["柱面（所有盘片同半径磁道）"] 磁头["磁头（每盘面一个）"] end 盘片 --> 磁道 --> 扇区 盘片 --> 柱面 磁头 -.->|读写| 磁道

磁盘地址 ：柱面号 · 磁头号 · 扇区号

3.2 磁盘访问时间

访问时间 = 寻道时间 + 旋转延迟 + 传输时间
组成说明典型值（7200rpm）
寻道时间磁头移到目标磁道5–10 ms
旋转延迟等待目标扇区转到磁头平均 4.17 ms
传输时间实际读写数据通常很短

平均旋转延迟 = 60 / (2 × 转速 rpm) 秒

类型单元位数寿命成本

MLC2 bit中等中等

SSD 关键技术 ：磨损均衡（Wear Leveling）、垃圾回收（GC）、TRIM 命令、FTL（闪存转换层）。

四、高速缓冲存储器（Cache）

4.1 Cache 工作原理

flowchart TD A["CPU 发地址"] --> B{"Cache 命中?"} B -->|命中| C["直接读 Cache<br/>返回数据"] B -->|缺失| D["从主存读块<br/>调入 Cache"] D --> E["更新 Cache 行"] E --> C

关键指标 ：

  • 命中率 ：访问命中 Cache 的比例
  • 平均访问时间 = 命中率 × 命中时间 + 缺失率 × (命中时间 + 缺失代价)

4.2 三种映射方式

flowchart TB subgraph 直接映射["直接映射 Direct Mapped"] DM1["主存块 → 唯一 Cache 行<br/>行号 = 块号 mod 行数"] end subgraph 全相联["全相联 Fully Associative"] FA1["主存块 → 任意 Cache 行<br/>需并行比较所有 Tag"] end subgraph 组相联["N 路组相联 Set Associative"] SA1["主存块 → 唯一组<br/>组内任意行"] end
映射方式冲突缺失硬件复杂度命中时间
直接映射最高最低最短
组相联中等中等中等
全相联最低最高最长

4.3 地址结构（以直接映射为例）

flowchart LR subgraph 地址["32 位物理地址"] direction LR Tag["Tag<br/>标记位"] Index["Index<br/>行索引"] Offset["Offset<br/>块内偏移"] end Tag --> 比较["并行比较<br/>Tag + 有效位"]

4.4 替换算法与写策略

替换算法 ：

算法思想特点
随机随机选行简单，性能一般
FIFO替换最早调入可能换掉常用数据
LRU替换最久未用命中率高，硬件复杂
Clock近似 LRU实现简单，常用

写策略 ：

策略说明
写直达（Write Through）同时写 Cache 和主存，一致性好但慢
写回（Write Back）只写 Cache，替换时才写回主存，快但可能不一致
写分配写缺失时先调入 Cache
非写分配写缺失时直接写主存

五、虚拟存储器

5.1 虚拟存储器概述

虚拟存储器为每个进程提供独立、连续、巨大的虚拟地址空间，通过 MMU 将虚拟地址映射为物理地址。

与 Cache 的对比 ：

特性Cache虚拟存储器
目标弥补 CPU 与主存速度差弥补主存与磁盘容量差
管理方硬件OS + 硬件（MMU/TLB）
块大小16–128 B（Cache 行）4KB–2MB（页面）
缺失代价100 ns （访主存）10 ms （访磁盘）
透明性完全透明缺页由 OS 处理

5.2 地址翻译过程

flowchart LR subgraph 虚拟地址["虚拟地址"] VPN["虚拟页号 VPN"] Offset["页内偏移"] end VPN --> TLB{"TLB 查找"} TLB -->|命中| PPN1["物理页号 PPN"] TLB -->|缺失| PT["访问页表（内存）"] PT --> PPN2["物理页号 PPN"] PPN1 --> 物理地址 PPN2 --> 物理地址 subgraph 物理地址["物理地址"] PPN["物理页号 PPN"] Offset2["页内偏移（不变）"] end

5.3 缺页异常处理

sequenceDiagram participant CPU participant OS as 操作系统 participant Disk as 磁盘 CPU->>OS: 访问不在内存的页 → 缺页异常 OS->>OS: 保存现场，陷入内核 OS->>OS: 查找页在磁盘位置 alt 内存已满 OS->>OS: 选一页换出（置换算法） OS->>Disk: 脏页写回磁盘 end OS->>Disk: 读入所需页到内存 Disk-->>OS: 数据就绪 OS->>OS: 更新页表，标记有效 OS->>CPU: 恢复现场，重新执行指令

5.4 多级页表（x86-64 四级页表）

flowchart LR CR3["CR3<br/>PML4 基址"] --> PML4["PML4 索引<br/>9 位"] PML4 --> PDPT["PDPT 索引<br/>9 位"] PDPT --> PD["PDT 索引<br/>9 位"] PD --> PT["PT 索引<br/>9 位"] PT --> PPN["物理页号 PPN<br/>40 位"] PPN --> Offset["页内偏移<br/>12 位"]

优点 ：不需要为未使用的页表分配内存，节省空间。

5.5 存储保护

每个 PTE 包含保护位：

位含义
Valid页面是否在内存
R/W读/写权限
U/S用户/管理员态
Dirty是否被修改
Accessed是否被访问
NX是否禁止执行（防攻击）

六、现代技术扩展

6.1 新型存储技术

flowchart TB subgraph 新型存储["新型存储技术"] OPTANE["3D XPoint / Optane<br/>接近 DRAM 速度 + NAND 容量"] ZNAND["Z-NAND<br/>SLC 低延迟 NAND"] MRAM["MRAM / ReRAM / FeRAM<br/>下一代非易失"] end

6.2 CXL（Compute Express Link）

  • 基于 PCIe 5.0 的缓存一致性互连
  • 支持内存池化（Memory Pooling），多设备共享内存
  • 适用于 AI、高性能计算

6.3 Cache 优化技术

  • 硬件预取 ：流预取器、步长预取器，自动提前加载
  • 非时序访问（NT） ：只访问一次的数据绕过 Cache
  • Intel CAT ：L3 Cache 分区，防止"吵闹邻居"

6.4 大页与 THP

  • 传统 4KB 页 → TLB 命中率低
  • 大页（2MB/1GB）→ 减少 TLB 缺失
  • THP（透明大页） ：OS 自动合并小页为大页
  • 适用：数据库、JVM 堆等内存密集型应用

参考答案

选择题

  1. B 2. B 3. D 4. B 5. B 6. C 7. B 8. C

简答题要点

  1. 利用局部性原理，上层是下层缓存，在速度/容量/价格间平衡。
  2. SRAM 触发器不刷新、快、贵，用于 Cache；DRAM 电容需刷新、集成度高、便宜，用于主存。
  3. 直接映射硬件简单但冲突多；全相联冲突少但硬件复杂；组相联折中。
  4. 访问页不在内存时触发，OS 从磁盘调入，更新页表后重新执行。
  5. 优点：扩大地址空间、内存保护、共享、简化管理。与 Cache 都是层次存储，但管理方、块大小、缺失代价不同。
